# HIRFA Admin Dashboard

This is the admin dashboard for HIRFA, an Uber-for-craftsmen startup in Egypt.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- React Query
- Lucide React

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)

## Features
- **Dashboard Overview**: KPI cards and charts
- **Bookings Management**: View and filter bookings
- **Craftsmen Management**: Verify and manage craftsmen
- **Customers Management**: View customer profiles
- **Payments**: Revenue tracking and payouts
